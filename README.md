# 📚 Estruturas de Dados (2018)

Repositório acadêmico com programas, exercícios práticos, exemplos de aula e códigos desenvolvidos para a disciplina de **Estruturas de Dados** ministrada pelo **Prof. Edkallenn Lima** em 2018.

---

## 📂 Organização dos Tópicos

- 📁 `Aula01/` — Introdução, revisão de conceitos e configuração do ambiente.
- 📁 `Basico-Iteracao-Condicional/` — Fundamentos de lógica, desvios condicionais e laços de repetição.
- 📁 `Funcoes/` — Modularização de código, escopo e passagem de parâmetros por valor e referência.
- 📁 `VetoresMatrizes/` — Manipulação de arrays unidimensionais (vetores) e bidimensionais (matrizes).
- 📁 `Strings/` — Processamento e manipulação de cadeias de caracteres.
- 📁 `Structs/` — Estruturas heterogêneas de dados e tipos definidos pelo usuário.
- 📁 `AlocacaoDinamica/` — Ponteiros, gerenciamento de memória (`malloc`, `free`, `realloc`).
- 📁 `Ordenacao/` — Algoritmos clássicos de ordenação de dados (Bubble Sort, Insertion Sort, Selection Sort, etc.).

---

## 🛠️ Tecnologias e Compilação

Os exemplos foram desenvolvidos em **C / C++**. Para compilar qualquer um dos arquivos utilizando o `gcc` ou `g++`:

```bash
gcc -Wall -Wextra arquivo.c -o programa
./programa
```
